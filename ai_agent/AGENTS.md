# 프로젝트 전용 AGENTS

이 문서는 `/home/m2cl/dev/develop_python/ai_agent` 저장소에서만 적용하는 프로젝트 전용 작업 규칙이다.

## 언어

- 사용자 응답과 작업 메모는 기본적으로 한국어로 작성한다.

## 멀티 에이전트 운영

- 실제 비용이 발생하는 live 작업과 외부 API 호출 작업은 중복 실행 비용을 막기 위해 메인 에이전트 단독으로 수행한다.
- 특히 실제 웹툰 파이프라인 테스트, smoke 성격의 live 검증, 게시/업로드와 연결되는 실행에서는 서브 에이전트를 호출하지 않는다.
- 실제 파이프라인 테스트에 해당하는 대표 명령:
  - `./.venv/bin/python -m agents.webtoon.main pipeline ...`
- 사용자가 live run을 중단했거나 응답이 끊긴 경우, 다시 실행하기 전에 동일 파이프라인 프로세스가 백그라운드에 남아 있는지 먼저 확인한다.

## 코드 수정 작업

- 실제 live 파이프라인 실행이 아닌 일반 코드 수정, 리팩터링, 테스트 추가, 정적 조사, 원인 분석 작업에서는 작업 효율을 위해 멀티 에이전트 활용을 우선 검토한다.
- 멀티 에이전트를 사용할 때는 파일 소유 범위와 하위 작업 범위를 분리해 중복 수정과 충돌을 줄인다.
- live 실행 결과를 해석하거나 후속 수정안을 만드는 작업은 서브 에이전트를 사용할 수 있지만, 같은 live 명령을 다시 돌리게 하면 안 된다.

## 웹툰 프로젝트 일반화 규칙

- `독일생활 적응기`, `독일 생활 에피소드`라는 프로젝트의 상위 콘셉트는 고정 유지한다.
- 다만 특정 에피소드 주제 하나를 반복 테스트했다고 해서 그 주제 하나에만 맞춘 예시, 규칙, 보정 문구, 프롬프트를 하드코딩하지 않는다.
- 프롬프트, OCR 보정, 품질 게이트, 소품 연속성 규칙은 항상 여러 주제에 재사용 가능한 형태로 일반화한다.

## 검증

- 코드 수정 후에는 가능한 한 관련 pytest와 정적 검사를 먼저 통과시킨 뒤 live run을 수행한다.
- live run은 같은 목적에 대해 한 번만 실행하고, 추가 실행이 필요하면 이유를 명확히 남긴다.
