# Fonts

텍스트 후처리 렌더링에 사용할 폰트를 이 폴더에 넣습니다.

권장:
- 한글과 독일어를 모두 지원하는 `ttf`, `otf`, `ttc` 폰트 1개 이상
- 예: `NotoSansKR-Regular.ttf`
- 말풍선 기본 대사는 한국어이므로, 한글 글리프가 완전한 폰트를 우선 사용

우선순위:
1. 환경변수 `WEBTOON_FONT_FILE`
2. 이 폴더 안 첫 번째 폰트 파일
3. 시스템 기본 폰트

배치 기준:
- 말풍선 텍스트는 후처리로 직접 렌더링한다
- 결과물은 `썸네일 1장 + 개별 컷 4장`의 총 5장 슬라이드로 생성된다
- 각 말풍선은 개별 패널 이미지 안쪽 좌상단 또는 우상단에 배치되고, 꼬리는 패널 내부 캐릭터 방향으로 내려오게 그린다
- 독일어 표지판, 기계 UI 텍스트는 배경 이미지에 남을 수 있지만 말풍선 대사는 한국어를 유지한다
- 대사는 가독성을 위해 보통 1~2줄을 우선하지만, 내용이 어색해지면 3줄까지 허용한다

주의:
- 시스템 기본 폰트에는 한글 글리프가 없을 수 있습니다.
- 한글 대사를 정확히 그리려면 직접 폰트 파일을 넣는 것이 안전합니다.
