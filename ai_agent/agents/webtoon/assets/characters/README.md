# Character Assets

이 폴더에 항상 같은 외형으로 유지할 고양이 참조 이미지를 넣습니다.

권장 파일명:
- `black_cat.png`
- `gray_cat.png`
- `character_sheet.png`

운영 규칙:
- 가능한 한 배경이 단순한 정면/측면/표정 변화 이미지 2~3장을 사용합니다.
- 파이프라인은 이 폴더와 하위 폴더의 `png`, `jpg`, `jpeg`, `webp` 파일을 자동으로 읽습니다.
- 우선순위는 `black_cat.png`, `gray_cat.png`, `character_sheet.png`이고, 나머지 이미지는 뒤에 추가 참조로 함께 전달됩니다.
